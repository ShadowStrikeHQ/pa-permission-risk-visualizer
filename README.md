# pa-permission-risk-visualizer
Generates a visual representation of permission risks, highlighting over-permissioned users and potential privilege escalation paths. Can output graphs in formats like DOT or PNG. - Focused on Tools for analyzing and assessing file system permissions

## Install
`git clone https://github.com/ShadowStrikeHQ/pa-permission-risk-visualizer`

## Usage
`./pa-permission-risk-visualizer [params]`

## Parameters
- `-h`: Show help message and exit
- `-o`: No description provided
- `-f`: No description provided
- `-v`: No description provided
